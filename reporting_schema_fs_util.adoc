= File System Utilization Schema
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ./media/

[.lead]
The File System Utilization schema tracks storage consumption and usage patterns across file systems, hosts, and compute resources. Use this schema to identify capacity hotspots and optimize storage allocation at the file system level.

Source: *dwh_fs_util* OData endpoint — Data Infrastructure Insights
